# MarmPaper — coated-bubble tests for the Marmottant paper

This folder holds every run needed for the paper. All five decks are generated by `sizing/gen_paper.py`, which writes this folder and `TryonSlurmFiles/FlowMarmottant/FlowMarmPaper/`. To change something shared, edit the generator and rerun it.

## Common setup (all decks)

**Bubble and shell**
- Coated air bubble in water, R0 = 2 µm, centred at the origin.
- Marmottant shell:
  - χ = 1.0 N/m;
  - R_buck = 0.98 R0, so σ(R0) = 0.0412 N/m and the elastic band is R/R0 = 0.980–1.015;
  - σ_break = 0.073, σ_water = 0.0728;
  - κ_s = 7.2e-9 kg/s (the micro-scale equivalent of κ_s = 0.72 at R0 = 2 cm).
- Water viscosity μ = 1e-3; inviscid gas.
- Stiffened-gas water (γ 2.35, p∞ 1e9), ideal-gas air.

**Linearised dynamics (Keller–Miksis + Marmottant)**
- Natural frequency f0 = **4.084 MHz** (T0 = 244.8 ns). The shell elasticity 4χ/R0 dominates; Minnaert alone gives 1.63 MHz.
- Damping: shell ζ ≈ 0.14, viscous ζ ≈ 0.04.

**Numerics**
- RK3, MUSCL2, HLLC, cfl 0.5.
- ε/dx_finest = 2, AMR on the η band.
- NSCBC outflow far field.
- The interface jump, tensor curvature and relaxation closure are built into the code (flag audit 2026-11-05), so the decks no longer set them.

**THINC.** Each deck carries commented-out THINC qq lines for the second round. The keys are `Limiter.thinc.<key>`. `Limiter.thinc_mode` is silently ignored.

**Output.** `amr.thermo.plot_dt` writes `thermo.dat` at high cadence:
- `gas_volume`, giving R_vol(t) = (6 V/π)^{1/3} in the octant;
- `gas_pressure_int`;
- `kinetic_energy`;
- `interface_area`.

**Forced nonlinear: choice of drive** (`sizing/km_sub.py`)
- With this shell's damping there is no subharmonic below about 3.5 bar.
- Between 3.6 and 4.5 bar, period doubling is robust for f/f0 = 0.9–1.1, and R_min stays > 0.5 R0 throughout. That is the validation target.
- 4 bar at f0 sits in the middle of that window.

**Jetting.** An impulsively started velocity patch first sheds a short acoustic pulse of about ρcU/2 (~4e7 Pa at 50 m/s). It is sub-ns and decays as 1/r. What remains is the solenoidal jet.
- The jet's dynamic pressure, ρU²/2 = 1.25e6 Pa, is far above the gas (1.4e5) and Laplace (4e4) pressures, so the jet should pierce the bubble.
- Raise `U` in the `velocity{0,1}.ic` constants for a faster jet.

## Octant ↔ full domain

The octant decks carry the full-domain blocks, commented out, directly under the active ones:
- the GEOMETRY block (prob_lo/hi, n_cell, refine_box);
- the BC block: NSCBC on all six faces, plus `nscbc.{x,y,z}lo.*`, including the drive on the driven decks.

To run the full domain, comment out the octant lines and uncomment the full-domain lines in **both** blocks. Base dx is unchanged, so the full domain has 8× the cells. Analysis: in the octant, R_vol uses 8 × gas_volume; in the full domain use gas_volume directly.

## Drive amplitude: box gain

With an NSCBC drive, the pressure the bubble sees is not `drive_amp`. The box resonates, and the static symmetry faces reflect.

The gain was measured with liquid-only runs: same box and BCs, 32³, drive 1e4 Pa, a fit of p − p∞ = A sin(ωt + φ) after 2 periods. The scripts are `~/claude_scratch/marmpaper/gain*`.

| Box | f | gain at centre | gain at mid-box | phase |
|---|---|---|---|---|
| 100 R0 octant | f0/π | 1.329 | 1.250 | 1.6° |
| 100 R0 octant | f0 | **9.24** | 5.46 | 168° (near the box resonance: unusable) |
| 20 R0 octant | f0 | 1.107 | 1.089 | 0.2° |
| 20 R0 octant | f0/π | 1.006 | 1.007 | 0.2° |

The driven decks therefore use the 20 R0 box, and set `drive_amp = (target at the bubble) / gain`. The free decks keep the 100 R0 Light_Mili box (no drive). For the KM comparison, use p∞(t) = p∞ + A_bubble sin(ωt + φ) with A_bubble and φ from the gain table. Better still, use the far-field pressure measured in the run.

## Running

- **Slurm:** `TryonSlurmFiles/FlowMarmottant/FlowMarmPaper/<deck>.sh` for each deck. Partition `compute-long`, 500 h, 1 node × 128 tasks; jetting uses 4 nodes.
- **Binary:** hydro2 built from the flag-audit code or later.
- **Analysis:** `../reference/analyze_octant_bubble.py` (KM comparison; uses `../reference/marmottant_rpe_km.py`, which supports a drive).
- **Sizing scripts:** `sizing/km_size.py` (f0, damping, free / collapse / linear sizing), `sizing/km_sub.py` (subharmonic scan), `sizing/km_onset.py` (cycles to steady state).

## `_Cross` variants (2026-11-09): rate-dependent shell viscosity

Every deck has an `input_<deck>_Cross` twin (Slurm: `<deck>_Cross.sh`, job name + `X`). The only differences are the plot_file path and one line:

```
shell.kappa_s_alpha = 4.0e-6    # Mili decks: 4.0e-2 (same dimensionless rate, like kappa_s x 1e8)
```

This switches on the Cross-law shell viscosity κ_eff = κ_s / (1 + α|div_s u|/2), from Doinikov, Haac & Dayton (Ultrasonics 49:269, 2009). With constant κ_s the buckled shell carries an unbounded compressive viscous tension, and the 02 collapse crashes from grid-scale wrinkling (see `bin/CollaseDebug/collapse_debug.pdf`).

- **Local 02 slab:** survives the collapse and the rebound to 100 ns (constant κ_s: NaN at 34.9 ns). R(t) follows KM with almost no shell viscosity.
- **Local 02 octant:** still NaN at ~29.6 ns, from a symmetry-axis runaway that is still under investigation.
- **Caveat:** κ_s is **not** re-fitted for the Cross law, so buckled-phase damping is weaker than Marmottant KM. In the 01 slab, R_min is 0.782, against 0.824 with constant κ_s and 0.787 from RP with the Cross law.
- **Binary:** needs hydro2 built from code that has `shell.kappa_s_alpha` (2026-11-09 or later).
